# FastHire

Create a beautiful, fully functional web app called GovTrust AI for Indian students. Include an input box for pasting a part-time job description. On clicking “Analyze & Verify via Government Registry,” show an automated AI-style analysis with a dynamic green/red Safety Score meter, a checklist of verified metrics including GSTIN check, CIN check, and standard payment-risk analysis, plus a mock student-friendly summary report. Make the interaction feel real with loading and varied result states; use clear disclaimers that registry checks are simulated/demo data unless integrated with live official sources.
